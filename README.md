# Machine Learning Notes

A curated collection of machine learning tutorials, hands-on projects, and reference notebooks covering the full ML workflow — from Python fundamentals to applied classification models.

## Overview

This repository is organized into progressive learning modules, each with Jupyter notebooks that combine theory with practical implementation:

| Module | Description |
|--------|-------------|
| [Python](./Python/) | Core Python syntax, data structures, and programming constructs |
| [NumPy](./Numpy/) | Numerical computing with ndarrays, vectorization, and linear algebra operations |
| [Pandas](./Pandas/) | Data manipulation, cleaning, aggregation, and DataFrame operations |
| [Matplotlib](./matplotlib/) | Data visualization — line plots, bar charts, histograms, and customization |
| [Projects](./projects/) | End-to-end ML projects including classification and pattern recognition |
| [Dataset](./dataset/) | Reusable datasets for training and experimentation |

## Featured Projects

- **Breast Cancer Detection** — Binary classification model to predict malignant vs. benign tumors using cell nucleus features
- **Iris Classification** — Classic multiclass classification on the Iris flower dataset
- **Shape Identification** — Pattern recognition model for identifying geometric shapes

## Tech Stack

- **Language:** Python 3
- **Libraries:** NumPy, Pandas, Matplotlib, Scikit-learn
- **Environment:** Jupyter Notebook (.ipynb)

## Getting Started

1. Clone the repo:
   ```bash
   git clone https://github.com/PREMRAJESH/Machine_learning_notes.git
   ```
2. Install dependencies:
   ```bash
   pip install numpy pandas matplotlib scikit-learn jupyter
   ```
3. Launch Jupyter:
   ```bash
   jupyter notebook
   ```
4. Navigate to any notebook and run the cells.
